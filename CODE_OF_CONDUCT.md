# Code of Conduct

## Our commitment

This project is built for families and groups of friends, and we hold ourselves to
the same warmth and respect internally. Everyone contributing to `<Suite>` — whether
human or AI assistant — is expected to act professionally, kindly, and inclusively.

## Expected behaviour

- Be respectful, constructive, and patient in reviews and discussions.
- Assume good intent; disagree on ideas, never attack people.
- Use inclusive, welcoming language. Documentation and code are in English.
- Respect privacy: never commit real personal data, secrets, or credentials.

## Unacceptable behaviour

- Harassment, discrimination, or demeaning comments of any kind.
- Publishing others' private information without consent.
- Sustained disruption of discussions or reviews.

## Scope

This applies to all project spaces: the repository, issues, pull requests, commit
messages, and documentation.

## Enforcement

Concerns may be raised with the project maintainer. Reports will be handled
confidentially and in good faith.

---

*This is a lightweight code of conduct for a small private project; it will be
expanded if and when the contributor base grows.*
