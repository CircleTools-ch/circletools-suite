# Naming — Suite & Apps

The final brand name is **not yet locked**. Until it is, the codebase uses the placeholder token
**`Suite`** (namespaces/projects) and **`<Suite>`** (prose). Finalizing the name is the first
tracked step of the roadmap.

## Decisions taken
- **Language:** English names.
- **TLD:** `.ch`-first (Swiss audience); matching `.com` is a nice-to-have, not required.
- **App domains:** apps are **subdomains** of the suite domain (e.g. `secretsanta.<suite>.ch`), so
  only **one** suite domain is needed. Per-app brand names are decided during each app's idea step.
