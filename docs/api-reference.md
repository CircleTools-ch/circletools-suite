# API Reference

The C# API reference is generated by DocFX from XML documentation comments in the `src/`
projects.

> **This section is empty during the harness phase** because no code projects exist yet. Once
> the first projects are added, the DocFX `metadata` step will generate the API reference and
> this tab will link into it (see the `docfx/docfx.json` configuration and
> [ADR-0002](adr/0002-use-arc42-c4-docfx.md)).

To regenerate locally once code exists:

```bash
dotnet docfx docfx/docfx.json
```
